# Delapan profil keputusan PT XYZ

Pilih profil untuk membuka uraian kasusnya. P1 memuat jaringan, data dasar, dan aturan operasi. P2–P8 menjelaskan perubahan pada permintaan, penanganan gudang, atau tujuan. Semua profil dapat dijalankan pada tingkat rute Low, Medium, dan High.
